# RLCD Settings

## Register
product

## Users
The owner of a Windows PC and an RLCD Monitor, configuring the screen at their desk.

## Product Purpose
Open settings from the tray, see connection status, edit existing configuration and save without restarting the collector.

## Brand Personality
Clear, practical, quiet. Chinese interface, light appearance similar to Windows Settings, confirmed by the user.

## Anti-references
Decorative dashboards, promotional landing pages and terminal-style configuration editors.

## Design Principles
- Keep common settings immediately understandable.
- Preserve existing settings and offer explicit save feedback.
- Show actual connection state rather than simulated readings.
- Run inside the existing executable with no separate runtime.

## Accessibility & Inclusion
Labeled native inputs, keyboard navigation, visible focus, readable contrast, responsive layout and no decorative motion.
